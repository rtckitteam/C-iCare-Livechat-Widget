Signed-in Customer

The identity comes from the page, so the customer never fills in a form — one tap starts the chat.

This box is a testing aid only. In your app the key is written straight into the data-widget-key attribute.

Option A — server-rendered page (PHP, Laravel, Django, Rails, .NET)

The safest route: the identity is printed from the server-side session, never from user input.

<!-- Laravel / Blade -->
<div id="livechat-app"
     class="livechat-widget"
     data-widget-key="YOUR_WIDGET_KEY"
     data-name="{{ auth()->user()->name }}"
     data-email="{{ auth()->user()->email }}"
     data-phone="{{ auth()->user()->phone }}"></div>

<script type="module" crossorigin
        src="https://cdn.example.com/widget/widget.js"></script>

Your template engine escapes these values for you. If you build the HTML as a string yourself, escape them — a customer's name can contain a quote character.

Option B — browser-rendered page (React, Vue, Angular, any SPA)

Set the attributes first, then load the bundle. The widget reads them once, at startup, so the order matters.

<div id="livechat-app" class="livechat-widget"></div>

<script>
  // user comes from your app's own session
  var user = window.currentUser;
  var el = document.getElementById('livechat-app');

  el.setAttribute('data-widget-key', 'YOUR_WIDGET_KEY');
  if (user.name)  el.setAttribute('data-name',  user.name);
  if (user.email) el.setAttribute('data-email', user.email);
  if (user.phone) el.setAttribute('data-phone', user.phone);

  // load the bundle AFTER the attributes are in place
  var s = document.createElement('script');
  s.type = 'module';
  s.crossOrigin = 'anonymous';
  s.src = 'https://cdn.example.com/widget/widget.js';
  document.body.appendChild(s);
</script>

Do not set empty attributes. data-email="" counts as absent, but it is cleaner to leave out any attribute whose value you do not have.

When the user signs out or switches account

The widget keeps the chat session in the browser's localStorage under the cwidget_ prefix. Clear it on sign-out so one user's conversation does not follow the next one, then reload the page.

Object.keys(localStorage)
  .filter(function (k) { return k.indexOf('cwidget_') === 0; })
  .forEach(function (k) { localStorage.removeItem(k); });

location.reload();
